<h1 align="center">OpenControl для Windows</h1>
<p align="center">Доступ к вашей корпоративной сети · Windows 10 / 11</p>
<p align="center"><b>Русский</b> · <a href="README.en.md">English</a></p>

Независимый VPN-клиент для Kerio Control на базе OpenControl Protocol Library.
Адрес частного корпоративного сервера и учётную запись предоставляет администратор
вашей организации. Проект не предоставляет VPN-серверы или доступ к ним.

## Установка

[Скачать MSI](https://github.com/nr084/opencontrol-client-windows-releases/releases).
Выберите архитектуру в «Параметры → Система → О системе → Тип системы»:

| Система | Пакет |
|---|---|
| Windows 10/11, Intel/AMD 64 бит | `x64` |
| Windows 10, 32 бит | `x86` |
| Windows 10/11, ARM64 | `arm64` |

Один MSI на архитектуру, установщик на русском. В приложении оба языка доступны
по кнопке RU/EN. Windows 11 не имеет 32-битной редакции; для неё используйте x64
или ARM64. Требуются права администратора. Сначала выберите «Выход» в меню трея при обновлении
или удалении. Установщик включает официальный подписанный Wintun 0.14.1.
Отдельно устанавливать драйвер не нужно; адаптер создаётся при подключении.
Ярлыки в меню «Пуск» и на рабочем столе создаются по умолчанию для всех пользователей.

EXE/MSI проекта пока не имеют Authenticode-подписи издателя. Это отличается от
действительной подписи включённого драйвера WireGuard LLC. Проверяйте SHA256SUMS.

## Первое подключение

1. Откройте «Профили», введите название, сервер, порт (обычно 4090), имя и пароль.
2. Для сохранения пароля включите отдельный флажок. Сохраните профиль.
3. На вкладке подключения прочтите уведомление о передаче трафика и нажмите «Подключить».
4. При отсутствии доверенного сертификата клиент автоматически получает его и открывает
   подтверждение. Сверьте SHA-256 с администратором по доверенному каналу и подтвердите
   доверие: подключение продолжится автоматически. Повторное подтверждение не требуется,
   пока сертификат остаётся прежним и действительным. Альтернатива — PEM доверенного CA.

Просроченный сертификат требует отдельного явного согласия для конкретного SHA-256.
При замене сертификата подключение останавливается и требуется новая проверка.
Сертификат с будущей датой начала действия не принимается. До подтверждения пароль
серверу не передаётся. «Получить сертификат» остаётся доступным для ручной проверки.

## Трей и масштаб интерфейса

Значок трея присутствует с запуска до выхода, в том числе без подключения.
Крестик окна скрывает его в трей и сохраняет VPN. После успешного подключения
окно также автоматически скрывается.
Зелёная галочка означает активный VPN; красный крестик — отсутствие соединения,
включая попытки восстановления. Левый щелчок открывает окно. Правый щелчок открывает
меню «Открыть OpenControl», «Отключить», «Выход». Выход сначала отключает VPN.
При недоступном значке трея окно остаётся открытым.

Интерфейс использует PerMonitorV2: текст и элементы масштабируются при переносе
между мониторами с разным DPI. Значки состояния перерисовываются под масштаб экрана.
Проверен программный рендер RU/EN на 100%, 125%, 150% и 200%; проверка на физических
мониторах с разным DPI пока не выполнена.

## Возможности

- Импорт/экспорт QR-профилей Android (PNG); экспортируемый QR содержит пароль.
- Несколько профилей, профиль по умолчанию, защищённое хранение паролей DPAPI.
- Русский и английский интерфейс, светлая и тёмная темы, значок Android-клиента.
- TLS, шифрованный UDP, смена ключей, защита от повторного воспроизведения пакетов.
- Повторные ROUTES без пересоздания адаптера и сброса ключей при неизменных маршрутах.
- После первого успешного соединения — восстановление до явного отключения.
- Счётчики трафика и ограниченный журнал состояний без паролей и содержимого пакетов.
- Без настройки split tunneling: нет выбора приложений или исключений сетей.
  Маршруты VPN задаёт корпоративный сервер.

## Границы первой версии

Это первая предварительная версия 0.3.0. Автоматические тесты и сборки не заменяют
проверку с вашим Kerio Control. Проверка на реальном корпоративном сервере и на
физическом ARM64-устройстве пока не подтверждена. См. [проверки](VALIDATION.md).

Протокол передаёт IPv4; внешний адрес сервера должен разрешаться в IPv4. При
полном IPv4-маршруте глобальный IPv6 направляется в адаптер и отбрасывается.
Общесистемного kill switch нет: между переподключениями обычная сеть доступна.
«Выход» в меню трея отключает VPN; фоновой службы и автозапуска до входа в Windows нет.
Поведение DNS Windows зависит также от системной и корпоративной политики.

Настройки находятся в `%LOCALAPPDATA%\OpenControl\profiles.json`. Пароли сохраняются
только как DPAPI-блоки текущего пользователя; данные не переносимы на другую учётную
запись простым копированием. Удаление MSI сохраняет пользовательские профили.

[Конфиденциальность](PRIVACY.md) · [English privacy policy](PRIVACY.en.md)

Этот публичный репозиторий содержит только пользовательские документы и релизы.
Исходники клиента хранятся в отдельном приватном репозитории. Публичная
[OpenControl Protocol Library](https://github.com/nr084/opencontrol-protocol) —
отдельный проект. Kerio Control является товарным знаком своего правообладателя;
клиент не является официальным продуктом Kerio/GFI.

## Импорт из Kerio VPN

При первом запуске, если найден `%APPDATA%\Kerio\VpnClient\user.cfg`, приложение
предлагает просмотреть соединения. Ничего не переносится до нажатия «Импортировать».
Вкладка «Профили» → «Импорт Kerio VPN…» позволяет выбрать файл вручную, в том числе
после пропуска первого предложения. Файл используется только для чтения.

Переносятся названия, серверы, порты, логины и сохранённые пароли D3S. Пароли защищаются Windows DPAPI;
сертификаты нужно проверить перед подключением. Автозапуск и доверие из Kerio не переносятся.
Адреса через точку с запятой создаются как отдельные профили. Совпадения по серверу,
порту и логину пропускаются; существующие профили не заменяются. Лимит — 100 профилей.
Итог импорта показывает количество добавленных и пропущенных записей.

Для неподдерживаемых или повреждённых записей пароля импорт показывает необходимость ручного ввода. Пароли не отображаются при предварительном просмотре и не записываются в журнал.

Windows может поместить значок в область скрытых значков. Чтобы он был рядом с часами, включите его отображение в настройках панели задач.

Главное окно показывает сервер и логин выбранного профиля. Кнопка «Настроить» открывает профиль; сохранение пароля доступно прямо на экране подключения.
