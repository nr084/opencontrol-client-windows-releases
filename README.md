<h1 align="center">OpenControl Client</h1>
<p align="center">VPN для частных сетей Kerio Control · Windows 10 и 11</p>
<p align="center"><b>Русский</b> · <a href="README.en.md">English</a></p>
<p align="center"><a href="https://github.com/nr084/opencontrol-client-windows-releases/releases/latest">Скачать 1.5.0</a> · <a href="RELEASE_NOTES.md">Changelog</a> · <a href="SHA256SUMS">SHA256</a></p>

Для подключения понадобятся адрес Kerio Control и учётные данные от вашей организации. OpenControl Client — независимый VPN-клиент.

## Установка

| Windows | Установщик |
|---|---|
| 64-разрядная Windows на Intel или AMD | [x64](https://github.com/nr084/opencontrol-client-windows-releases/releases/download/v1.5.0/OpenControl-client-1.5.0-windows-x64.msi) |
| 32-разрядная Windows 10 | [x86](https://github.com/nr084/opencontrol-client-windows-releases/releases/download/v1.5.0/OpenControl-client-1.5.0-windows-x86.msi) |
| Windows 11 на ARM, включая виртуальную машину на Mac | [arm64](https://github.com/nr084/opencontrol-client-windows-releases/releases/download/v1.5.0/OpenControl-client-1.5.0-windows-arm64.msi) |

Каждый MSI включает русский и английский. При первом запуске выбран русский, язык переключается кнопкой **EN / RU**. После установки откройте **Профили**, добавьте соединение или импортируйте его из Kerio, затем включите VPN. При первом подключении сверьте отпечаток сертификата с администратором.

## Одновременно до десяти VPN

1. Во вкладке **Настройки** задайте число подключений от 1 до 10.
2. Во вкладке **Подключение** откройте нужную подвкладку, например **Подключение 2**, выберите профиль и нажмите **Сохранить**. Затем включите туннель переключателем вверху.
3. В трее открывайте меню нужного номера, чтобы сменить профиль, отключить или переподключить только этот туннель.

![Подключения OpenControl Client](assets/connections-ru.png)

Два независимых Kerio могут работать одновременно, если их корпоративные сети маршрутизируются однозначно. Можно также использовать первый туннель для интернета, а второй для сети филиала. VPN автоматически поднимается после входа или до входа в Windows только для подключения 1. Остальные включаются вручную.

Подключение 1 может принимать маршрут по умолчанию и назначать VPN DNS Windows. Дополнительные подключения используют маршруты к своим сетям. Для них доступны соединения по IP и имена, которые уже разрешает настроенный DNS. Одинаковые подсети, адреса серверов и выданные VPN IP могут конфликтовать. При неоднозначном совпадении OpenControl отклоняет конфликтующий маршрут или туннель. Закрытые сети планируйте с различными подсетями.

## Что ещё умеет клиент

| Раздел | Возможности |
|---|---|
| Профили | Сортировка, сохранение паролей средствами Windows, экспорт QR, ручной режим совместимости со старыми серверами |
| Настройки | Импорт из Kerio с выбором файла и обработкой дублей, экспорт, двусторонняя синхронизация с `user.cfg`, управление автозапуском |
| Сети | Один список для всех подключений. Можно исключить указанные сети или пропускать через VPN только указанные сети, доступные через соответствующий сервер |
| Трей | Активные профили, общий трафик, уведомления с номером и именем туннеля, двойной щелчок для открытия или скрытия окна |
| Журнал | Время, номер подключения, профиль, подключение, отключение и ошибки |
| О программе | Версия клиента и Rust, дата сборки, ссылка на GitHub, ручная проверка обновления |

## Проверки и ограничения

Wintun подписан издателем драйвера. EXE и MSI OpenControl не имеют подписи издателя. Сверяйте [SHA256](SHA256SUMS). Штатное удаление доступно в списке установленных приложений Windows. Сведения о данных и лицензиях приведены в [политике конфиденциальности](PRIVACY.md) и [уведомлениях о сторонних компонентах](THIRD-PARTY-NOTICES.txt).
