# Конфиденциальность

[English](PRIVACY.en.md)

OpenControl для Windows отправляет учётные данные указанному вами корпоративному
серверу по TLS после проверки его сертификата. IP-пакеты, соответствующие маршрутам
сервера, передаются в шифрованном туннеле. Организация, управляющая сервером, определяет
его обработку данных. Разработчик клиента не предоставляет доступ к этому серверу.

Телеметрии, рекламных SDK и автоматической отправки журналов нет. Просмотр сертификата
обращается к выбранному серверу без передачи пароля. Внешняя ссылка на GitHub открывает
страницу GitHub, на которую распространяется его политика.

Профили хранятся локально. Сохранение пароля добровольное, с шифрованием Windows DPAPI
для текущего пользователя. Пароль сеанса в настройках не сохраняется. Журнал в памяти
содержит только состояния подключения, не содержимое трафика. Удаление профиля удаляет
его сохранённый секрет. MSI не удаляет профили автоматически.

Сети, явно исключённые пользователем, передаются через обычное подключение вне VPN, включая DNS-серверы в этих сетях. Список исключений хранится локально и применяется ко всем профилям. Уведомление Windows содержит название подключённого профиля; пароли в уведомления не включаются.
