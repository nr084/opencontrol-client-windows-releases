# Конфиденциальность

[English](PRIVACY.en.md)

OpenControl для Windows отправляет учётные данные указанному вами корпоративному
серверу по TLS после проверки его сертификата. IP-пакеты, соответствующие маршрутам
сервера, передаются в шифрованном туннеле. Организация, управляющая сервером, определяет
его обработку данных. Разработчик клиента не предоставляет доступ к этому серверу.

Телеметрии, рекламных SDK и автоматической отправки журналов нет. Просмотр сертификата
обращается к выбранному серверу без передачи пароля. Внешняя ссылка на GitHub открывает
страницу GitHub, на которую распространяется его политика.

Профили хранятся локально. Сохранение пароля добровольное, с шифрованием Windows DPAPI
для текущего пользователя. Пароль сеанса в настройках не сохраняется. Журнал в памяти
содержит только состояния подключения, не содержимое трафика. Удаление профиля удаляет
его сохранённый секрет. MSI не удаляет профили автоматически.

Сети, явно исключённые пользователем, передаются через обычное подключение вне VPN, включая DNS-серверы в этих сетях. Список исключений хранится локально и применяется ко всем профилям. Уведомление Windows содержит название подключённого профиля; пароли в уведомления не включаются.

## Служба и локальные файлы (0.6)

Интерфейс работает от обычного пользователя. Служба LocalSystem получает параметры VPN и пароль только по локальному каналу Windows с ограниченными правами доступа; удалённые клиенты запрещены. Учётные данные хранятся в памяти на время соединения, не записываются службой на диск и не отправляются разработчику. Завершение клиентского процесса закрывает его сессию.

По явному выбору пользователя экспорт и двусторонняя синхронизация записывают список соединений и сохранённые пароли в выбранный локальный CFG. Пароли в CFG используют обратимый формат Kerio D3S; защита DPAPI относится к локальному хранилищу OpenControl, а не к переносимому CFG. Синхронизация включает удаления и может быть отключена в настройках. Удаление программы сохраняет пользовательское хранилище и выбранные внешние файлы.


Проверка обновлений автоматически раз в сутки и по кнопке обращается к публичному GitHub API и серверам загрузки GitHub. Передаются обычные данные HTTPS-запроса, включая IP-адрес и версию клиента в User-Agent. Профили, серверы VPN, логины, пароли и журналы туда не отправляются. Время проверки и номер уведомлённой версии сохраняются локально; MSI временно хранится в локальном кэше обновлений.
